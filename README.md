# Dart Training

React + TypeScript + Vite foundation for the dart training app.

## Local development

Use Node.js 22.12 or newer and npm.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. Stop the server with Ctrl+C.

```powershell
npm run build
npm run lint
npm run preview
```

The app currently contains the official Vite starter screen and counter only.
Training features will be implemented in later steps.

See REQUIREMENTS.md for product requirements and AGENTS.md for project instructions.
